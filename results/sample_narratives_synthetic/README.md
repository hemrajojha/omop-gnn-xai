# Synthetic sample narratives

One **synthetic** patient (not derived from any real record) explained for the four personas: clinician, patient, auditor and ML engineer. The files show the output format of `neo4j_xai/narrative_explainer.py`.

Narratives for real MIMIC-IV patients are not published. The MIMIC-IV data use agreement does not allow sharing patient-level data, including derived outputs. Run the pipeline with your own credentialed access to generate them.
